# 不等号数独 · Inequality Sudoku

比较符号（不等号）数独网页游戏。基础题为谜题书上的「谜题014」，经照片颜色分离提取、
求解器唯一解验证与人工逐条目检修正；引擎数据驱动、题目非硬编码，可生成多种自洽变体。

## 玩法与规则

1. 标准数独规则：每行、每列、每个 3×3 宫各含 1–9；
2. 格子边界上的 `> < ∧ ∨` 是相邻两格的大小关系，**尖头指向较小的数**；
   - `>`：左格 > 右格；`<`：右格 > 左格；
   - `v`（尖朝下）：上格 > 下格；`^`（尖朝下相反）：下格 > 上格；
3. **区间提示**：选中任意空格，实时显示当前全部约束下的可行数字集合
   （数独候选 ∩ 邻接约束上下界）。

## 功能

- 📖 基础书题 014（12 给定数 + 28 比较符号，恰好唯一解）
- 🎲 随机新题生成器（简单/中等/困难；每题出口前过「恰有一解」验证）
- 🔁 同构变体（行/列/带置换 + 转置，从变换后的解重推符号方向；
  位置变换保序故唯一性天然保持——数字置换对不等号数独不成立，引擎已明确不支持）
- 💡 提示（优先填唯一候选格；盘面有冲突时先拒答）、✓ 检查、解答、撤销、重开
- ✏️ 候选笔记（填数自动清理同行/列/宫笔记）、同数高亮、冲突实时标红
- ⌨️ 键盘：方向键移动、1–9 填数、`N` 笔记、`H` 提示、`Ctrl/Cmd+Z` 撤销、`Del/0` 擦除
- 🌗 双主题：书风蓝（纸面感）/ 自然色系（仓库设计系统），一键切换
- ⏱️ 计时 + 本地自动存档（刷新续玩）

## 题面数据格式（新增题目往 `src/data/puzzles.ts` 加）

```ts
{
  id: 'my-puzzle',
  name: '我的题',
  spec: { rows: 9, cols: 9, boxRows: 3, boxCols: 3 },
  givens: [{ addr: { r: 1, c: 2 }, value: 7 }, ...],
  constraints: [{ type: '>', a: { r: 1, c: 3 }, b: { r: 1, c: 4 } }, ...],
  solution: [[...]],   // 建议提供权威解；变体生成依赖它
}
```

约束语义：`type: '>'` 表示 `a > b`；`'<'` 表示 `a < b`；`'='` 表示相等（引擎支持）。
坐标采用国际通行 RxCy：`r1c1` 为左上角。

## 工程结构

```
src/core/      引擎：solver（求解/计数/可行域）、variants（置换变体）、
               generator（随机出题）、engine（对局状态机，React 无关）
src/data/      题库（纯数据）
src/components/Board / Keypad / Controls / WinOverlay
```

## 质量闸

- 求解器对一切内置/生成/变体题目做「恰有一解」验证，fail-closed：不唯一不出题；
- 测试覆盖：基础题回归（解=人工核验答案）、题面-权威解自洽性、变体同构、
  生成器唯一性、数字置换不保唯一性的反例存档；
- 交付前自查 6 项缺陷经 jev 结构化严重度裁定：2 项 P2 已修（存档结构校验、
  「不违规但错」暗雷检测与红标），3 项 P3 已修（隐藏页暂停计时、置灰只认正确数字、
  死代码），1 项 P3 记录为已知限制。

## 已知限制

- 撤销历史不持久化：刷新后无法撤销刷新前的操作（对局进度本身会恢复）；
- 提示优先填「唯一候选格」，无唯一候选时按权威解填入首格，不保证教学意义的最优推理路径。
